# A Bolsa, o Vômito e o Ano Letivo

Flipbook HTML interativo do livro-jogo **A Bolsa, o Vômito e o Ano Letivo — Uma aventura das amigas mágicas**, ambientado na Escola da Fênix.

## Estrutura

- `index.html` — aplicação principal
- `styles.css` — identidade visual e diagramação
- `app.js` — navegação, modo mestre e progresso local
- `book-data-1.js` a `book-data-4.js` — conteúdo das 20 Folhas
- `assets/` — ilustrações do livro

## Publicação

O projeto é estático e pode ser publicado via GitHub Pages.
